# Fortune Association — Event Management System

A Flask + MySQL web app for managing college organization events, built with
a real ETL/analytics layer on top of the same operational data — built and
maintained as an evolving portfolio project (Full-Stack → Data Engineering).

## Features

- Student/admin authentication (hashed passwords, session-based)
- Admins manage academic years, historical events, and upcoming events
- Students browse upcoming events and register via external links
- **Analytics dashboard** — a real ETL pipeline aggregates event data into
  summary tables and charts, viewable at `/analytics`
- CSRF protection, connection-pooled MySQL access, paginated listings
- Automated tests (pytest) run via GitHub Actions CI on every push/PR

## Tech Stack

Python · Flask (application factory + blueprints) · MySQL · pandas ·
matplotlib · Flask-WTF (CSRF) · pytest · GitHub Actions

## Local Setup

1. Create and activate a virtual environment, then:
   ```
   pip install -r requirements-dev.txt
   ```
2. Copy `.env.example` to `.env` and fill in real values (a random
   `SECRET_KEY`, your MySQL credentials).
3. Create the database:
   ```sql
   SOURCE flaskr/fortune_association.sql;
   SOURCE etl/analytics_schema.sql;
   ```
4. (Optional but recommended) Seed some demo data:
   ```
   python seed_data.py
   ```
5. Run the app from the project root:
   ```
   python run.py
   ```
   Visit `http://127.0.0.1:5000`.
6. Run the ETL pipeline to populate the analytics dashboard:
   ```
   python etl/run_etl.py
   ```

## Running Tests

```
pytest -v
```
Tests mock the database entirely, so no live MySQL connection is needed to run them.

## Deployment

Connect this repo to Render or Railway — both auto-deploy on every push to
`main` using the included `Procfile`. Set the same environment variables
from `.env` in the platform's dashboard (never commit `.env` itself).
